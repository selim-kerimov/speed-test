# speed-test

Консольный скрипт на TypeScript, который измеряет скорость скачивания: делает 10 последовательных запросов к указанному адресу, дожидается полного ответа на каждый и печатает среднее время запроса, общий объём скачанных данных и скорость.

Зависимостей для запуска нет, используются только встроенные возможности Node.js (`fetch`, `parseArgs`, `styleText`, `readline`).

## Требования

- Node.js 24+: он запускает `.ts`-файлы напрямую, без сборки.

## Запуск

```bash
git clone https://github.com/selim-kerimov/speed-test.git
cd speed-test

node src/index.ts "https://speed.cloudflare.com/__down?bytes=25000000"
```

`pnpm install` для запуска не нужен, он нужен только для разработки (линтер, тесты, git-хуки).

Если запустить без адреса, скрипт спросит его интерактивно:

```bash
node src/index.ts
```

Адрес с `?` или `&` берите в кавычки, иначе zsh/bash попробуют его интерпретировать (`zsh: no matches found`).

### Параметры

```
node src/index.ts [url] [--count N] [--timeout MS]

  -n, --count    число последовательных запросов (по умолчанию 10)
  -t, --timeout  таймаут одного запроса в миллисекундах (по умолчанию 30000)
  -h, --help     справка
```

## Единицы измерения

| Величина      | Единица                            |
| ------------- | ---------------------------------- |
| Скорость      | Мбит/с (основная) и МБ/с в скобках |
| Время запроса | мс, от 1000 мс — секунды           |
| Объём         | B, KB, MB, GB                      |

Все единицы десятичные (SI): 1 Мбит = 1 000 000 бит, 1 МБ = 1 000 000 байт. Мегабиты в секунду выбраны основной единицей, потому что в них указывают скорость провайдеры и сервисы вроде speedtest.net, так результат проще сравнить.

## Как считается

- Время запроса: от отправки запроса до получения последнего байта тела ответа. Тело читается потоком, байты считаются по факту, а не по заголовку `Content-Length`.
- Среднее время = сумма времени всех запросов / число запросов. Дополнительно выводятся минимум и максимум.
- Общий объём = сумма байт тел всех ответов.
- Скорость = общий объём / суммарное время запросов:

  ```
  Мбит/с = байты × 8 / секунды / 1 000 000
  МБ/с   = Мбит/с / 8
  ```

Запросы выполняются строго по очереди: следующий начинается только после того, как предыдущий полностью получен.

Скрипт отправляет два заголовка:

- `Accept-Encoding: identity` просит не сжимать ответ, чтобы считать реальные байты, прошедшие по сети. Если сервер всё равно сжал ответ, скрипт предупредит, что скорость завышена;
- `Cache-Control: no-cache` просит кэши и CDN не отдавать сохранённую копию (некоторые CDN это игнорируют).

Если ответ не 2xx, запрос не укладывается в таймаут или сеть недоступна, скрипт выводит понятную ошибку и завершается с кодом 1.

## Пример вывода

Запуск против локального тестового сервера:

```

     4 sequential requests · timeout 30 s

  ✔ #1    578 ms     2.00 MB    27.70 Mbit/s
  ✔ #2    662 ms     2.00 MB    24.16 Mbit/s
  ✔ #3    641 ms     2.00 MB    24.97 Mbit/s
  ✔ #4    699 ms     2.00 MB    22.89 Mbit/s

  ────────────────────────────────────────────────────
  Requests      4
  Average time  645 ms  (min 578 ms · max 699 ms)
  Total data    8.00 MB  (8,000,000 bytes)
  Per request   █▇▇▇

  ⚡ Download speed  24.81 Mbit/s  (3.10 MB/s)
```

Пока идёт запрос, в терминале показывается спиннер и прогресс-бар (если сервер прислал `Content-Length`). `Per request` показывает мини-график скорости каждого запроса.

Если вывод перенаправлен в файл или пайп, анимация отключается и печатаются обычные строки без цвета. Цвета можно отключить и в терминале: `NO_COLOR=1 node src/index.ts <url>`.

## Ограничения

- Первый запрос обычно медленнее: в него входит установка соединения (DNS, TCP, TLS). Следующие запросы переиспользуют соединение. Для точности берите файлы от 10 Мбайт: на маленьких время соединения заметно занижает скорость.
- Скачивание идёт в один поток, поэтому результат может быть ниже, чем у speedtest.net или fast.com, которые качают в несколько потоков.
- Измеряется скорость до конкретного сервера, а не «скорость интернета» вообще.

## Структура

```
src/
├── index.ts    — точка входа: аргументы, цикл запросов, обработка ошибок
├── cli.ts      — разбор и проверка аргументов, текст --help
├── measure.ts  — один запрос: скачивание тела и замер времени
├── stats.ts    — среднее, min/max, объём, скорость
├── format.ts   — форматирование чисел, прогресс-бар, мини-график
└── ui.ts       — вывод в консоль: цвета, анимация, ввод адреса
test/           — тесты на node:test (без интернета, с локальным HTTP-сервером)
```
